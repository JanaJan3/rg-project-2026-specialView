# Stone Golem's Sanctuary

174/2021 - Ana Jovanović

Scena prikazuje kamenog golema koji čuva plutajuću platformu sa magičnim kristalom, 
unutar ruševina osvetljenih zalaskom sunca. Kristal je izvor point light-a 
koji obasjava i golema i platformu, dok directional light simulira sunčevu svetlost 
koja dolazi kroz arkade u pozadini.

## Controls

W -> pomeranje kamere napred  
S -> pomeranje kamere nazad  
A -> pomeranje kamere levo  
D -> pomeranje kamere desno  
Miš -> rotacija kamere  
B -> uključi/isključi GUI  
T -> pokreni lanac događaja (buđenje kristala)  
ESC -> izlazak iz aplikacije
